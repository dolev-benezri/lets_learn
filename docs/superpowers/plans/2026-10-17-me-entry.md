# Step 1 entry screen Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Until a new visitor chooses, step 1 shows the profile and progress cards centered with an import card ("ייבוא" or "הזנה ידנית"); the choice opens today's page.

**Architecture:** One localStorage flag (`entered()`) beside `onboarded()`. `renderMe` builds the profile and progress cards once and lays them out
either as the entry screen (`entryScreen()` = neither flag) or as today's page. `ACT.manualEntry` and a successful `importGrades` call one
helper that sets the flag, refreshes, and focuses the courses heading. CSS does the layout.

**Tech Stack:** ES modules, no build; `node --test`; `node-html-parser` in tests.

**Spec:** `docs/superpowers/specs/2026-10-17-me-entry-design.md`

## Global Constraints

- Copy, verbatim: step line `<b>צעד ראשון:</b> סמנו מה כבר עברתם. הכי מהיר: גליון הציונים מהפורטל.`; card heading "איך מסמנים מה עברתם?";
  "על מנת להתייחס לפטורים מקורסים מסוימים, העלו את גליון הציונים הרשמי של המכללה."; "הקובץ נקרא רק במכשיר שלך ולא נשמר.";
  buttons "ייבוא מגליון ציונים (PDF)" (primary, `data-act="gradeImport"`) and "הזנה ידנית" (`data-act="manualEntry"`).
- Flag key `afeka-sched-v1-entry`, value '1' (starts with `afeka-sched-v1`, so `clearSaved` erases it).
- `#gradeMsg` and `#gradeFile` appear exactly once per render. `h2#meTitle` stays the page focus target.
- Tokens only in CSS, light and dark. No emoji. Hit areas >= 44px. No horizontal scroll at 320.
- No requests to the Afeka site. Commits end with `Co-Authored-By: Claude Opus 5.5 <noreply@anthropic.com>`.

## Review Focus

- A returning user (onboarded, no entry flag; every user today) must get the regular page, and an import there must not move focus.
- After "הזנה ידנית" the clicked button is gone: focus must land on `#meCourses`, not `<body>`.
- A cancelled import dialog, an unreadable file, or a sheet with no courses must keep the entry screen and show the message.
- "הכול כבר מעודכן" ends the choice; its message must show on the regular page (`ui.gradeMsg`).
- Long track names and the progress text in two 50% columns at 720-900px: wrap, no overflow.

### Task 3 (added 2026-10-17 at the owner's request): a "פטור" tag for exemptions read from the grade sheet

Owner: "יש להוסיף בדיקה בייבוא של גליון הציונים מה קיבל פטור פנימי על מנת לסמן בהתאם את הקורסים"; asked what was missing, they chose a "פטור" tag on the row.
- State: `exempt: string[]` (DEFAULT `[]`, `normalize` keeps up to 200 strings of <= 20 chars). An exempt course is also in `passed` (credits, prerequisites).
- `setStatus`: any status but 'passed' drops the id from `exempt`.
- `gradeChanges`: an exempt row on a course already passed but not in `exempt` is offered (was = to = passed).
- `importGrades`: an applied row sets `exempt` membership from its result and keeps a grade only for 'passed'.
- `chip`: a passed exempt course shows `<span class="tag ok">פטור</span>` instead of the grade field.
- Tests: app (normalize), rules (setStatus), grade-import (gradeChanges), xss (the row).
