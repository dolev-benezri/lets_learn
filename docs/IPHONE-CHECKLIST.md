# בדיקה באייפון אמיתי (Safari)

בדיקות WebKit במחשב (`npm run test:browser`) מכסות את המנוע של Safari, אבל לא את האייפון עצמו: המסך, המקלדת, המגע וההדפסה. את עשרת הסעיפים האלה בודקים פעם אחת על אייפון אמיתי, בדפדפן Safari, לפני שמפיצים לסטודנטים. אחרי כל סעיף כותבים עבר או נכשל, ואם נכשל, מה ראיתם.

| # | מה בודקים | איך נראה "עבר" |
|---|---|---|
| 1 | פותחים את כתובת האתר בטאב חדש (לא במצב גלישה פרטית) | הדף נטען בעברית מימין לשמאל, בלי פס גלילה לצדדים, והטקסט קריא בלי להגדיל |
| 2 | מסך התנאים: מסמנים "קראתי והבנתי" ולוחצים "המשך" | הכפתור "המשך" כבוי עד הסימון, ואחרי הלחיצה מופיעה השאלה על המסלול |
| 3 | בוחרים מסלול, ואז שנת לימודים | כל לחיצה נרשמת בפעם הראשונה (בלי לחיצה כפולה), ובסוף מגיעים למסך "המצב שלי" עם הכפתור "הזנה ידנית" |
| 4 | "הזנה ידנית": מסמנים קורס כ"עברתי", ואז עוברים לשלב 4 (מערכות) | הקורס מסומן, ובשלב 4 מוצגת חלופה אחת לפחות עם שיעורים בלוח השבועי |
| 5 | בלוח: עוברים בין חלופות (החצים, ואז החלקה בין הימים) ופותחים שיעור בלחיצה | ההחלקה לא גוללת את כל העמוד הצידה, ופתיחת שיעור מציגה את הפרטים בלי להיחתך |
| 6 | "סיכום ליועץ" | נפתח חלון ההדפסה של iOS, והתצוגה המקדימה היא עמוד סיכום קריא ולא האתר כולו |
| 7 | "רשימה להרשמה", ואז "הוסף ללוח שנה" | הקובץ יורד או נפתח, ו-iOS מציע להוסיף את האירועים ליומן. באירוע כתוב שזו אינה הרשמה ואינה המלצה |
| 8 | בשלב 3 מסמנים "להציג גם הרצאה ותרגול מופרדים" | מופיע חלון אזהרה. "ביטול" מחזיר את הסימון למצב כבוי, "הבנתי, להציג" משאיר אותו דלוק |
| 9 | "מצב כהה" וחזרה, ואחר כך סוגרים את Safari לגמרי ופותחים שוב | המצב שנבחר נשמר, הנתונים שהוזנו עדיין שם, ובמצב כהה אין טקסט שלא נראה על הרקע |
| 10 | מסובבים את המסך לרוחב ובחזרה, ופותחים את המפה | העמוד מסתדר מחדש בלי להישבר, והמפה נפתחת, אפשר להזיז אותה באצבע, וסוגרים אותה בכפתור הסגירה |

## מה לא נבדק עדיין

מועדי בחינות: הבדיקה האמיתית שלהם מחכה ללוח הבחינות המפורסם. כשהוא יפורסם, מוסיפים כאן סעיף: בחינה מופיעה בלוח, בסיכום ליועץ ובקובץ היומן.
