# ארכיטקטורה

## מבנה הפרויקט

| נתיב | מה יש בו |
|---|---|
| `scripts/` | משיכת נתונים ובנייה: scrape, polite, parse, build, discover, audit, `programs.json`, ו-fixtures של HTML אמיתי |

| `web/rules.js` | מנוע התקנון: סיווג קורסים, התקדמות והתמחויות |
| `web/solver-core.js` | חיפוש: backtracking עם מסכות ביטים (ו-`solver-worker.js`) |
| `web/share.js` | קישורי חבר וגיבוי, עם אימות |
| `web/friend-*.js` | ייבוא מערכת חבר: טקסט, PDF, תמונה ועורך |
| `web/grade-import.js` | ייבוא ציונים |
| `web/ui-*.js` | ממשק: צד, לוח, מפה, חברים, חלונות |
| `web/map-*.js` | מפת ההתקדמות |
| `web/theme.js` | מצב בהיר או כהה, לפני הציור הראשון |
| `web/style.css` | כל העיצוב, מטוקנים (בהיר וכהה) |
| `web/data/afeka/` | הנתונים שנמשכו, `catalog.json` ו-`status.json` |
| `web/fonts/` | Rubik, מתארח מקומית |
| `web/vendor/` | עותקים מקומיים של pdf.js, panzoom ו-popover polyfill |
| `test/` | בדיקות `node --test` |
| `ci/` | סריקה לילית ל-GitLab CI |
| `docs/` | תיעוד, מחקר, specs ותוכניות |
| `design-system/` | מערכת העיצוב |

## ליבת הלוגיקה

- **תקנון** (תקנון הלימודים, עדכון 5.2.2026): אין חפיפה בין שיעורים (7.3), דרישת קדם חוסמת בשרשרת (7.4), קורס מקביל אפשר באותו סמסטר (6.2.3), קורס שנכשלת בו מוצע כחזרה (11.6.1), אזהרת "על תנאי" על כישלון ב-3 קורסים (11.4.1), ממוצע מתחת ל-65 (11.4.2) או פחות מ-70% מהתוכנית (11.4.4), ואזהרת הרחקה על 4 קורסים (11.5.1) או 3 כישלונות באותו קורס (11.5.2).
- **ייצוג:** שבוע כמסכות של 32 ביט ליום, משבצת לחצי שעה בין 07:00 ל-23:00. בדיקת חפיפה היא AND.
- **ציון:** סכום משוקלל של חברים, התקדמות, ימים פנויים, חלונות, שעות מחוץ לטווח ופיזור בחינות. יש מגבלת זמן, ואם מגיעים אליה מוצגות תוצאות חלקיות עם סימון.
- **בחינות:** כשהלוח לא פורסם (`examsPublished: false`) הממשק מציג "טרם פורסם".

## אבטחה ופרטיות

- הכול נשמר ב-localStorage בדפדפן בלבד. אין שרת ואין חשבון.
- קישורי חבר וגיבוי הם קלט לא מהימן: אימות מבנה, מגבלות גודל (4KB, 64KB, ו-256KB אחרי פריסה), בנייה מחדש שדה אחרי שדה ו-`normalize()` לפני הכניסה למצב. כל טקסט מוצג דרך `esc()`.
- הספריות pdf.js (ייבוא PDF וייבוא ציונים), panzoom (מפת ההתקדמות) וה-popover polyfill הן עותקים מקומיים ב-`web/vendor/`. הספרייה היחידה מבחוץ היא tesseract.js, מ-jsDelivr, שנטענת רק כשבוחרים תמונה בעורך החבר (עם נתוני השפה עברית ואנגלית). קובץ שנבחר נקרא בדפדפן ולא נשלח.
- **מדיניות אבטחה (CSP)** בשני הדפים: הכול מהאתר עצמו, בלי plugins ובלי שינוי של `base`. ב-`index.html` מותרים מ-jsDelivr רק הנתיבים של tesseract.js 7.0.0 (הסקריפט, ה-worker, ה-core ונתוני השפה), ו-`legal.html` לא טוען כלום מבחוץ. בהחלפת גרסה של tesseract.js צריך לעדכן את הנתיבים במדיניות. בדיקה ב-`test/app.test.mjs` אוכפת את זה.
- הפונט מתארח מקומית ואין בקשות ל-Google Fonts.
