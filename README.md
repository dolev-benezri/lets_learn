# בונה מערכת שעות לאפקה

כלי שבונה מערכת שעות לסמסטר מנתונים אמיתיים של מכללת אפקה. הוא מתחשב בתקנון הלימודים, בכישלונות ובחזרות על קורסים, ובמערכות של החברים שלך.

> **כלי עזר לא רשמי, בלי שום אחריות.** אין לו קשר למכללת אפקה. הנתונים עלולים להיות שגויים, וההרשמה באפקה-נט, הידיעון והתקנון הם הקובעים. השימוש כפוף ל[תנאי השימוש](TERMS.md).

**מצב נוכחי:** רץ מקומית. הנתונים מכסים הנדסת מכונות, מסלול יום, מחזור 2026, סמסטרים א׳ וב׳ תשפ״ז. תיעוד מלא של איך הפרויקט נבנה נמצא ב-[docs/HISTORY.md](docs/HISTORY.md).

## למה זה קיים

1. **כישלון בקורס משנה את כל המערכת.** מי שנכשל בקורס, למשל פיזיקה-מכניקה 90903, חייב לחזור עליו. בנוסף, כל הקורסים שהוא דרישת קדם שלהם נחסמים. הכלי מחשב את השרשרת הזו לבד ומראה מה עדיין אפשר לקחת.
2. **להישאר עם החברים.** ללמוד במערכת שונה מהחברים מתסכל. אפשר לייבא את מערכת החבר בקישור, והחיפוש מעדיף מערכות שיש בהן כמה שיותר שיעורים משותפים.
3. **ChoiceFreak ישן ולא מחשב.** הוא רק מציג את הקבוצות, ולא מחפש את המערכת הטובה ביותר לפי אילוצים והעדפות.

## מה אפשר לעשות

- **שנה מלאה:** החיפוש בונה זוג מערכות, סמסטר א׳ וסמסטר ב׳. קורס שלוקחים בא׳ פותח את ההמשך שלו בב׳. בוחרים "איפה להעמיס" (יותר בא׳, מאוזן, יותר בב׳), ולכל קורס שנלמד בשני הסמסטרים אפשר לבחור סמסטר. אפשר גם לתכנן סמסטר אחד בלבד.
- **מפת התקדמות:** כפתור "הראה התקדמות" פותח תרשים זרימה של כל הקורסים ודרישות הקדם, צבוע לפי המצב שלך. לחיצה על קורס מדגישה את כל השרשרת שלו.
- **פרופיל אישי:** שנת לימודים וציון אמירנט. לפי הציון, קורסי האנגלית שאין בהם צורך מסומנים "פטור".
- **מצב אישי:** מסמנים בצ'יפים לפי שנה אם עברת, נכשלת או נכשלת פעמיים בכל קורס. המערכת מראה התקדמות בנקודות זכות ואזהרות תקנון (לימודים על תנאי, הרחקה, 70% התקדמות).
- **מה לקחת:** כל קורס שמותר לך לקחת מופיע ככרטיס, ולכל כרטיס בורר של שלוש אפשרויות: `חובה | אולי | לא`. קורסים חסומים מופיעים עם הסיבה, למשל "חסום: דורש פיזיקה-מכניקה", וקורסים שלא נלמדים בסמסטר מופיעים בנפרד.
- **חיפוש אוטומטי:** כל שינוי מריץ את החיפוש מחדש תוך פחות משנייה, ברקע (Web Worker). אין כפתור "חפש".
- **לוח שבועי:** עד 10 חלופות מדורגות, עם מעבר ביניהן ב-‹ › או בחצי המקלדת. לכל קורס צבע משלו. לחיצה על שיעור פותחת את פרטי הקבוצה, את החברים שבה, נעיצה וקישור לידיעון.
- **נעיצה:** קבוצה נעוצה נכנסת לכל החלופות, והקורס שלה הופך אוטומטית לחובה.
- **העדפות:** בוחרים כמה חשוב כל דבר: חברים, התקדמות בתואר, ימים פנויים, בלי חלונות, שעות נוחות ופיזור בחינות. כל אחד בסולם של 4 דרגות. יום חופש וטווח שעות אפשר להגדיר כחובה או רק כהעדפה. יש גם תקרת נ״ז, אפשרות לשתי בחינות באותו יום ואפשרות לכלול קבוצות מלאות.
- **חברים:** מייבאים מערכת של חבר מקישור, קובעים כמה הוא חשוב לך, ומשתפים את שלך בחזרה. שיעור משותף מסומן בלוח בראשי התיבות של החבר.
- **רשימה להרשמה:** קוד, שם, קבוצה ותרגול לכל קורס, עם העתקה בלחיצה וקישור לידיעון.
- **גיבוי:** קישור פרטי שמכיל את כל המצב, לשחזור במחשב אחר.
- **כשאין פתרון:** אם אין מערכת שעומדת בכל האילוצים, המערכת מסבירה למה, למשל "X ו-Y מתנגשים בכל צירוף אפשרי".
- **נייד:** הלוח מופיע ראשון, יום אחד בכל פעם, וחלונות נפתחים מלמטה.

## התחלה מהירה

דרישות: Node.js בגרסה 22 ומעלה (נבדק על 24) ו-Git.

כל הפקודות רצות **מתוך תיקיית הפרויקט**. אם מריצים אותן מתיקייה אחרת, למשל תיקיית הבית ב-Windows, `npm install` מתקין חבילות של פרויקט אחר.

```bash
git clone https://github.com/<owner>/lets_learn.git
cd lets_learn
npm install
npx http-server web -p 8080 -c-1
```

אחר כך פותחים את http://localhost:8080/. אין שלב build: האתר הוא קבצים סטטיים.

**אם הפורט תפוס** (השגיאה `EADDRINUSE`), מריצים על פורט אחר, למשל `-p 8081`, ופותחים את http://localhost:8081/. כדי לבדוק מה תופס את הפורט ב-Windows: `Get-NetTCPConnection -LocalPort 8080` ב-PowerShell.

### בדיקות

```bash
npm test
```

בדיקות (`node --test`) מכסות את הפרסור, בניית הנתונים, התקנון, החיפוש, השיתוף, מצב האפליקציה והלוח.

### רענון הנתונים מהידיעון

```bash
node scripts/scrape.mjs --delay 2000
```

הריצה לוקחת כ-5 דקות. הקובץ `web/data/afeka/2027-1/30-2026.json` נכתב רק אם כל הבדיקות עוברות. אפשרויות:

| דגל | ברירת מחדל | משמעות |
|---|---|---|
| `--year` | `2027` | שנה אקדמית (2027 = תשפ״ז) |
| `--semester` | `א` | `א`, `ב` או `קיץ` |
| `--program` | `30` | קוד תוכנית (30 = הנדסת מכונות) |
| `--start` | `2026` | שנת התחלת המחזור |
| `--delay` | `1000` | השהיה במילישניות בין בקשות. מומלץ 2000, כי האתר חוסם הצפה |

### שיתוף עם חברים

האתר רץ מקומית, ולכן הקישור ששולחים לחבר מצביע על הכתובת שלך (localhost). החבר מריץ עותק משלו ומדביק את הקישור בשדה "הוסף חבר". הנתונים עצמם דחוסים בתוך הקישור, אחרי ה-`#`, ולא עוברים דרך שום שרת.

### מקור הנתונים

הנתונים נמשכים מהידיעון הציבורי של אפקה (`yedionpub.afeka.ac.il`), בלי התחברות: רשימות הקורסים לפי תוכנית, קבוצות ושעות, דרישות קדם ומקביל, ולוח בחינות. לוח הבחינות של תשפ״ז עוד לא פורסם, ולכן הקובץ מסומן `examsPublished: false` והממשק מציג "טרם פורסם".

### החיפוש

- **ייצוג:** השבוע מיוצג כמסכות של 32 ביט לכל יום, משבצת לכל חצי שעה בין 07:00 ל-23:00. בדיקת חפיפה היא פעולת AND.
- **אפשרויות לכל קורס:** כל צירוף של הרצאה ותרגול או מעבדה מקושרים. קבוצות מלאות מסוננות, אלא אם נעצת אותן.
- **חיפוש:** backtracking עם גיזום לפי חפיפות, תקרת נ״ז, בחינות באותו יום, אילוצי חובה ותנאי "מקביל". התוצאה היא 10 החלופות הטובות ביותר.
- **ציון:** סכום משוקלל של חברים (דקות משותפות), התקדמות (נ״ז ומספר הקורסים שהקורס פותח), ימים פנויים, חלונות, שעות מחוץ לטווח ופיזור בחינות.
- **ביצועים:** כ-150 מילישניות על הנתונים האמיתיים. יש מגבלת זמן, ואם מגיעים אליה מוצגות תוצאות חלקיות עם סימון.

### אבטחה ופרטיות

- כל הנתונים נשמרים ב-localStorage בדפדפן שלך בלבד.
- קישורי חבר וגיבוי הם קלט לא מהימן, ולכן הם עוברים אימות מבנה ומגבלות גודל: 4KB לקישור חבר, 64KB לגיבוי, ו-256KB אחרי פריסה. אחר כך הם נבנים מחדש שדה אחרי שדה, ועוברים דרך `normalize()` לפני שהם נכנסים למצב.
- כל טקסט שמוצג על המסך עובר `esc()`.
- שחזור גיבוי מבקש אישור לפני שהוא מחליף מצב קיים.
