# בונה מערכת שעות לאפקה

[![deploy](https://github.com/dolhack/lets_learn/actions/workflows/deploy.yml/badge.svg)](https://github.com/dolhack/lets_learn/actions/workflows/deploy.yml)

**האתר: https://dolhack.github.io/lets_learn/**

כלי שבונה מערכת שעות לסמסטר מנתונים אמיתיים של מכללת אפקה. הוא מתחשב בתקנון הלימודים, בכישלונות ובחזרות על קורסים, ובמערכות של החברים שלך.

> **כלי עזר לא רשמי, שאינו קשור למכללת אפקה.** הנתונים נלקחים מהידיעון הציבורי ועלולים להיות שגויים או ישנים, וההרשמה באפקה-נט היא הקובעת. הכלי ניתן כמות שהוא, בלי שום אחריות. ראו [תנאי השימוש](TERMS.md).

**כיסוי נוכחי:** הנדסת מכונות, מסלול יום, מחזור 2026, סמסטרים א׳ וב׳ תשפ״ז.

---

## למי זה ולמה

- **כישלון בקורס משנה את כל המערכת.** מי שנכשל בקורס חייב לחזור עליו, וכל קורס שהוא דרישת קדם שלו נחסם. הכלי מחשב את השרשרת ומראה מה עדיין אפשר לקחת.
- **להישאר עם החברים.** מייבאים מערכת של חבר בקישור, והחיפוש מעדיף מערכות עם הרבה שיעורים משותפים.
- **חיפוש לפי אילוצים והעדפות**, ולא רק הצגה של רשימת הקבוצות.

## מה אפשר לעשות

- **שנה מלאה:** זוג מערכות, סמסטר א׳ וב׳, כשקורס מא׳ פותח את ההמשך שלו בב׳. אפשר גם לתכנן סמסטר אחד.
- **מצב אישי ותקנון:** מסמנים לכל קורס אם עברת או נכשלת. הכלי מראה התקדמות בנקודות זכות, חוסם קורסים לפי דרישות קדם ומזהיר מלימודים על תנאי והרחקה. קורסי אנגלית מסומנים "פטור" לפי ציון אמירנט.
- **חיפוש אוטומטי:** בכל שינוי החיפוש רץ מחדש ברקע (Web Worker), ומציג עד 10 חלופות מדורגות על לוח שבועי.
- **חברים:** ייבוא מערכת בקישור, מילוי בעורך מסך מלא, או הדבקת טקסט, PDF או תמונה. שיעור משותף מסומן בלוח.
- **העדפות:** חברים, ימים פנויים, בלי חלונות, שעות נוחות ופיזור בחינות, כל אחד בסולם של 4 דרגות. יום חופש וטווח שעות אפשר להגדיר כחובה.
- **עוד:** מפת התקדמות של קורסים ודרישות קדם, נעיצת קבוצה, רשימה להרשמה עם קישורים לידיעון, גיבוי בקישור פרטי, והסבר כשאין פתרון. הלוח עובד גם בנייד.

## איך משתמשים

1. נכנסים לאתר ומגדירים בפרופיל שנת לימודים וציון אמירנט (אופציונלי).
2. מסמנים אילו קורסים עברת או נכשלת בהם.
3. ב"הקורסים שלי" בוחרים לכל קורס `חובה | אולי | לא`. המערכות נבנות מיד.
4. מדפדפים בין החלופות ב-‹ › או בחצי המקלדת. לחיצה על שיעור פותחת פרטים ונעיצה.
5. כדי ללמוד עם חבר: ב"חברים" מדביקים את הקישור שהוא שלח, ושולחים לו את שלך.
6. לבסוף פותחים את הרשימה להרשמה ומעתיקים אותה לאפקה-נט.

## למפתחים

### הרצה מקומית

דרישות: Node.js 22 ומעלה (נבדק על 24) ו-Git. אין שלב build, האתר הוא קבצים סטטיים.

```bash
git clone https://github.com/dolhack/lets_learn.git
cd lets_learn
npm ci
npx http-server web -p 8080 -c-1
```

פותחים את http://localhost:8080/. אם הפורט תפוס (`EADDRINUSE`), מחליפים ל-`-p 8081`. כל הפקודות רצות מתוך תיקיית הפרויקט.

### בדיקות

```bash
npm test
```

מריץ `node --test` על תיקיית `test/`: פרסור, בניית נתונים, תקנון, חיפוש, שיתוף, מצב האפליקציה והלוח.

### זרימת הנתונים

```
yedionpub.afeka.ac.il  ->  scripts/scrape.mjs  ->  web/data/afeka/  ->  GitHub Pages
        (ידיעון ציבורי)     (GitLab CI, כל לילה)    (commit ל-main)     (deploy.yml)
```

1. **משיכה ובנייה:** `scripts/scrape.mjs` עובר על הידיעון הציבורי (בלי התחברות), `parse.mjs` מפרסר את ה-HTML, `build.mjs` מאחד לפורמט אחד ומריץ `validate()`.
2. **כתיבה בטוחה:** קבצים נכתבים רק אם כל הבדיקות עוברות, וקובץ שלא השתנה לא נכתב מחדש. `status.json` מתעדכן בכל ריצה מוצלחת, והאתר קורא ממנו את שורת "נבדק לפני..." שבכותרת.
3. **ריצה לילית:** [ci/gitlab-scrape.yml](ci/gitlab-scrape.yml) רץ בתזמון של GitLab CI (השרתים של GitHub Actions לא מצליחים להתחבר לידיעון), מוסיף commit ודוחף ל-`main`.
4. **פריסה:** push ל-`main` שנוגע ב-`web/` מפעיל את [.github/workflows/deploy.yml](.github/workflows/deploy.yml), שמפרסם את `web/` ב-GitHub Pages.

ריצה ידנית (רק כשצריך, והיא פונה לאתר אמיתי):

```bash
node scripts/scrape.mjs --all-semesters
```

| דגל | ברירת מחדל | משמעות |
|---|---|---|
| `--year` | `2027` | שנה אקדמית (2027 = תשפ״ז) |
| `--semester` | `א` | `א`, `ב` או `קיץ` (נדרס על ידי `--all-semesters`) |
| `--program` | `30` | קוד תוכנית (30 = הנדסת מכונות) |
| `--start` | `2026` | שנת התחלת המחזור |
| `--all-semesters` | כבוי | בונה כל סמסטר שיש לו מפגשים, במעבר אחד |
| `--delay` | `2500` | השהיה במילישניות בין בקשות (±500 אקראי) |
| `--force` | כבוי | ממשיך גם כשבדיקת הבטיחות מול הנתונים הקודמים נכשלת |

אין `--help`: דגל לא מוכר גורם לשגיאה.

**נימוס כלפי האתר:** בקשה אחת בכל פעם, כ-170 בקשות וכ-8 דקות לריצה מלאה. ה-User-Agent הוא `afeka-scheduler/1.1 (+https://github.com/dolhack/lets_learn)`. דף ההגבלה השעתית או שלוש דחיות ברצף עוצרים את הריצה, `Retry-After` מכובד, ואז שום קובץ לא נכתב והריצה הבאה מתחילה מאפס. פרטים ב-[TERMS.md](TERMS.md).

### מבנה הפרויקט

```
scripts/        משיכת נתונים ובנייה: scrape, polite, parse, build (+ fixtures של HTML אמיתי)
web/            האתר: HTML + ES modules, בלי build
  app.js          מצב, normalize(), localStorage, טעינת נתונים
  rules.js        מנוע התקנון: סיווג קורסים והתקדמות
  solver-core.js  חיפוש: backtracking עם מסכות ביטים (+ solver-worker.js)
  share.js        קישורי חבר וגיבוי, עם אימות
  ui-*.js         ממשק: צד, לוח, מפה, חברים, חלונות
  data/afeka/     הנתונים שנמשכו
  fonts/          Rubik (מתארח מקומית)
test/           בדיקות node --test
ci/             סריקה לילית ל-GitLab CI
docs/           היסטוריה, מחקר, specs ותוכניות
design-system/  מערכת העיצוב
```

### ליבת הלוגיקה

- **תקנון** (תקנון הלימודים, עדכון 5.2.2026): אין חפיפה בין שיעורים (7.3), דרישת קדם חוסמת בשרשרת (7.4), קורס מקביל אפשר באותו סמסטר (6.2.3), קורס שנכשלת בו מוצע כחזרה (11.6.1), אזהרות על 3 כישלונות (11.4.1) ו-4 או 3 באותו קורס (11.5.1, 11.5.2), ומד התקדמות מול 70% (11.4.4).
- **ייצוג:** שבוע כמסכות של 32 ביט ליום, משבצת לחצי שעה בין 07:00 ל-23:00. בדיקת חפיפה היא AND.
- **ציון:** סכום משוקלל של חברים, התקדמות, ימים פנויים, חלונות, שעות מחוץ לטווח ופיזור בחינות. יש מגבלת זמן, ואם מגיעים אליה מוצגות תוצאות חלקיות עם סימון.
- **בחינות:** לוח הבחינות של תשפ״ז עוד לא פורסם (`examsPublished: false`), והממשק מציג "טרם פורסם".

### אבטחה ופרטיות

- הכול נשמר ב-localStorage בדפדפן בלבד. אין שרת ואין חשבון.
- קישורי חבר וגיבוי הם קלט לא מהימן: אימות מבנה, מגבלות גודל (4KB, 64KB, ו-256KB אחרי פריסה), בנייה מחדש שדה אחרי שדה ו-`normalize()` לפני הכניסה למצב. כל טקסט מוצג דרך `esc()`.
- ספריות חיצוניות נטענות בעת הצורך בלבד, מ-CDN: panzoom (jsDelivr) בפתיחת מפת ההתקדמות, ו-pdf.js (cdnjs) או tesseract.js (jsDelivr) בבחירת קובץ בעורך החבר. קובץ שנבחר נקרא בדפדפן ולא נשלח.
- הפונט מתארח מקומית ואין בקשות ל-Google Fonts.

### תרומה לפרויקט

- `main` מכיל את האתר העובד, וכל שינוי נבנה בענף נפרד שיוצא ממנו.
