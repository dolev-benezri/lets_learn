# בונה מערכת שעות לאפקה

[![deploy](https://github.com/dolhack/lets_learn/actions/workflows/deploy.yml/badge.svg)](https://github.com/dolhack/lets_learn/actions/workflows/deploy.yml)

**האתר: https://dolhack.github.io/lets_learn/**

כלי שבונה מערכת שעות לסמסטר מנתונים אמיתיים של מכללת אפקה. הוא מתחשב בתקנון הלימודים, בכישלונות ובחזרות על קורסים, ובמערכות של החברים שלך.

> **כלי עזר לא רשמי, שאינו קשור למכללת אפקה.** הנתונים נלקחים מהידיעון הציבורי ועלולים להיות שגויים או ישנים, וההרשמה באפקה-נט היא הקובעת. הכלי ניתן כמות שהוא, בלי שום אחריות. ראו [תנאי השימוש](https://dolhack.github.io/lets_learn/legal.html).

## למי זה ולמה

- **כישלון בקורס משנה את כל המערכת.** מי שנכשל בקורס חייב לחזור עליו, וכל קורס שהוא דרישת קדם שלו נחסם. הכלי מחשב את השרשרת ומראה מה עדיין אפשר לקחת.
- **להישאר עם החברים.** מייבאים מערכת של חבר בקישור, והחיפוש מעדיף מערכות עם הרבה שיעורים משותפים.
- **חיפוש לפי אילוצים והעדפות**, ולא רק הצגה של רשימת הקבוצות.

## מה אפשר לעשות

- **בחירת תוכנית ומחזור:** מסלול ושנת לימודים קובעים את התוכנית, את המחזור ואת רשימות הקורסים שלו.
- **שנה מלאה:** זוג מערכות, סמסטר א׳ וב׳, כשקורס מא׳ פותח את ההמשך שלו בב׳. אפשר גם לתכנן סמסטר אחד, וסמסטר קיץ נתמך ונספר.
- **מצב אישי ותקנון:** מסמנים לכל קורס אם עברת או נכשלת. הכלי מראה התקדמות בנקודות זכות, חוסם קורסים לפי דרישות קדם ומזהיר מלימודים על תנאי והרחקה. קורסי אנגלית מסומנים "פטור" לפי ציון אמירנט.
- **התמחויות:** בחירת התמחות בשנה ג׳ לפי כלל המחלקה: אחת, שתיים, או תחום אחד לבד.
- **חיפוש אוטומטי:** בכל שינוי החיפוש רץ מחדש ברקע (Web Worker), ומציג עד 10 חלופות מדורגות על לוח שבועי.
- **חברים:** ייבוא מערכת בקישור, מילוי בעורך מסך מלא, או הדבקת טקסט, PDF או תמונה. שיעור משותף מסומן בלוח.
- **העדפות:** חברים, ימים פנויים, בלי חלונות, שעות נוחות ופיזור בחינות, כל אחד בסולם של 4 דרגות. יום חופש וטווח שעות אפשר להגדיר כחובה.
- **עוד:** מפת התקדמות של קורסים ודרישות קדם, נעיצת קבוצה, רשימה להרשמה עם קישורים לידיעון, גיבוי בקישור פרטי, והסבר כשאין פתרון. הלוח עובד גם בנייד.

## איך משתמשים

1. נכנסים לאתר ובוחרים מסלול ושנת לימודים. אפשר להוסיף גם ציון אמירנט (אופציונלי).
2. מסמנים אילו קורסים עברת או נכשלת בהם.
3. ב"הקורסים שלי" בוחרים לכל קורס `חובה | אולי | לא`. המערכות נבנות מיד.
4. מדפדפים בין החלופות ב-‹ › או בחצי המקלדת. לחיצה על שיעור פותחת פרטים ונעיצה.
5. כדי ללמוד עם חבר: ב"חברים" מדביקים את הקישור שהוא שלח, ושולחים לו את שלך.
6. לבסוף פותחים את הרשימה להרשמה ומעתיקים אותה לאפקה-נט.

## למפתחים

### הרצה מקומית

דרישות: Node.js 22 ומעלה (נבדק על 24) ו-Git. אין שלב build, האתר הוא קבצים סטטיים.

```bash
git clone https://github.com/dolhack/lets_learn.git
cd lets_learn
npm ci
npx http-server web -p 8080 -c-1
```

פותחים את http://localhost:8080/. אם הפורט תפוס (`EADDRINUSE`), מחליפים ל-`-p 8081`. כל הפקודות רצות מתוך תיקיית הפרויקט.

### בדיקות

```bash
npm test
```

מריץ `node --test` על תיקיית `test/`: פרסור, בניית נתונים, הגדרות התוכניות, תקנון, חיפוש, שיתוף, מצב האפליקציה והלוח.

### זרימת הנתונים

```
yedionpub.afeka.ac.il  ->  scripts/scrape.mjs  ->  web/data/afeka/  ->  GitHub Pages
        (ידיעון ציבורי)     (GitLab CI, כל לילה)    (commit ל-main)     (deploy.yml)
```

1. **הגדרות:** [scripts/programs.json](scripts/programs.json) מגדיר כל תוכנית: מחלקה, מחזורים, רשימות הקורסים של כל מחזור, התמחויות, כלל בחירת התמחות, נקודות זכות לתואר וקורס עוגן לבדיקה.
2. **משיכה ובנייה:** `scripts/scrape.mjs` עובר על הידיעון הציבורי (בלי התחברות), `parse.mjs` מפרסר את ה-HTML, `build.mjs` מאחד לפורמט אחד ומריץ `validate()`.
3. **כתיבה בטוחה:** קבצים נכתבים רק אם כל הבדיקות עוברות, וקובץ שלא השתנה לא נכתב מחדש. `validate()` דורש מספר מינימלי של קורסים ואת קורס העוגן בכל מחזור ובכל סמסטר. `status.json` מתעדכן בכל ריצה מוצלחת, והאתר קורא ממנו את שורת "נבדק לפני..." שבכותרת, ו-`catalog.json` קובע אילו תוכניות ומחזורים מוצגים.
4. **ריצה לילית:** [ci/gitlab-scrape.yml](ci/gitlab-scrape.yml) רץ בתזמון של GitLab CI (השרתים של GitHub Actions לא מצליחים להתחבר לידיעון), מוסיף commit ודוחף ל-`main`. הודעת ה-commit היא שורת סיכום אחת, עם עד 6 קבצים ו-"ועוד N מתוך M קבצים".
5. **פריסה:** push ל-`main` שנוגע ב-`web/` מפעיל את [.github/workflows/deploy.yml](.github/workflows/deploy.yml), שמפרסם את `web/` ב-GitHub Pages.

הנתונים נשמרים בקבצים `web/data/afeka/{שנה}-{סמסטר}/{תוכנית}-{מחזור}.json`, למשל `2027-1/30-2026.json`.

### משיכה ידנית

רק כשצריך, והיא פונה לאתר אמיתי:

```bash
node scripts/scrape.mjs --all-semesters                                  # תוכנית אחת (30), מחזור אחד
node scripts/scrape.mjs --all-semesters --all-programs --programs 20,30 --cache cache   # תוכניות נבחרות
node scripts/scrape.mjs --all-semesters --all-programs --cache cache     # כל התוכניות
node scripts/scrape.mjs --all-semesters --all-programs --cache cache --offline   # בנייה מהמטמון, בלי אף בקשה
```

| דגל | ברירת מחדל | משמעות |
|---|---|---|
| `--year` | `2027` | שנה אקדמית (2027 = תשפ״ז) |
| `--semester` | `א` | `א`, `ב` או `קיץ` (נדרס על ידי `--all-semesters`) |
| `--program` | `30` | קוד תוכנית יחידה, לפי `programs.json` |
| `--start` | `2026` | שנת התחלת המחזור, לתוכנית יחידה |
| `--all-semesters` | כבוי | בונה כל סמסטר שיש לו מפגשים, במעבר אחד |
| `--programs` | | עם `--all-programs`: רק התוכניות ברשימה (מופרדת בפסיקים), לכל המחזורים שלהן |
| `--all-programs` | כבוי | כל התוכניות שב-`programs.json`, לכל המחזורים |
| `--cache` | | תיקייה ששומרת כל תשובה של האתר, כדי להמשיך ריצה שנעצרה או לבנות בלי רשת |
| `--offline` | כבוי | עם `--cache`: בונה רק מהמטמון, ושגיאה אם חסרה תשובה |
| `--nightly` | כבוי | עם `--cache`: קבוצות ובחינות נמשכות בכל ריצה, ורשימות, פרטי קורסים ודפי מסלול פעם בשבוע |
| `--wait-throttle` | כבוי | ממתין לשעה שבה נגמרת ההגבלה השעתית ואז ממשיך, במקום להיכשל |
| `--delay` | `2500` | השהיה במילישניות בין בקשות (±500 אקראי) |
| `--force` | כבוי | ממשיך גם כשבדיקת הבטיחות מול הנתונים הקודמים נכשלת |

אין `--help`: דגל לא מוכר גורם לשגיאה.

**נימוס כלפי האתר:** בקשה אחת בכל פעם, וההגבלה של האתר היא כ-400 בקשות בשעה. משיכה ראשונה של כל התוכניות היא כ-1,800 בקשות, ולכן היא נמשכת כמה שעות, וכל תשובה נשמרת במטמון. אחר כך הריצה הלילית היא כ-450 בקשות (קבוצות ובחינות). ה-User-Agent הוא `afeka-scheduler/1.1 (+https://github.com/dolhack/lets_learn)`. שלוש דחיות ברצף עוצרות את הריצה, `Retry-After` מכובד, ואז שום קובץ לא נכתב. פרטים ב-[התנאים](https://dolhack.github.io/lets_learn/legal.html).

**הריצה הלילית הראשונה:** המטמון של GitLab ריק בהתחלה, ומשיכה מלאה ארוכה מריצה אחת. `timeout 160m` עוצר את הסורק לפני ש-GitLab הורג את ה-job, המטמון נשמר (`when: always`), והריצה נחשבת חלקית: ירוקה, בלי commit. הריצה הבאה ממשיכה מהמטמון, ולכן משיכה ראשונה לוקחת 2-3 לילות. הריצה החלקית הרביעית ברצף נכשלת, כדי שסריקה תקועה תשלח מייל.

### מעבר שנת לימודים

האתר לוקח את השנה האקדמית מ-`catalog.json`, שהסורק כותב, והמטמון נשמר בתיקייה נפרדת לכל שנה (`.yedion-cache/2028`). כשהידיעון של השנה הבאה מתפרסם:

1. משנים את ברירת המחדל של `--year` ב-`scripts/scrape.mjs`.
2. ב-`scripts/programs.json`, לכל תוכנית: מוסיפים את המחזור החדש ל-`cohorts` ואת קודי הרשימות שלו ל-`lists`, ומורידים את המחזור הישן.
3. ב-`web/ics.js` מוסיפים ל-`SEMESTER_DATES` את תאריכי הסמסטרים ואת הימים בלי לימודים, מתוך [לוח השנה האקדמי](https://www.afeka.ac.il/about-afeka/general-information/academic-calendar/). בלי השורה הזו, כפתור הייצוא ללוח שנה כבוי.
4. מריצים `npm test` ומחכים לריצה הלילית. קישורי גיבוי מהשנה הקודמת ממשיכים לעבוד: הקורסים, הציונים וההעדפות נשמרים, ונעיצות, חברים ושיוך לסמסטר נמחקים. קישורי חבר מהשנה הקודמת נדחים.

### הוספת תוכנית

1. `node scripts/discover.mjs --cache cache --offline > draft.json` מפיק טיוטת הגדרות מהמטמון: מסלולים, מחזורים, רשימות והתמחויות.
2. מעתיקים את הטיוטה ל-`scripts/programs.json` ומשלימים ידנית את מה שלא מופיע באתר: `deptName` (מילת האוכלוסייה בדרישות הקדם), `anchor` (קורס שחייב להופיע בכל מחזור וסמסטר), `degree`, `specRule`, ולפעמים `minCourses` לתוכנית קטנה.
3. משאירים `verified: false` עד שכל שדה שמולא ביד נבדק מול תוכנית הלימודים הרשמית של התוכנית, ומוסיפים את הקישור אליה לטבלה למעלה.
4. מריצים `npm test` ו-`--offline` על המטמון, ובודקים בדפדפן.
5. `node scripts/audit.mjs` מדפיס סקירת נתונים אוטומטית (קורסי חובה שלא נפתחים, דרישות קדם שבורות, סכומי נ״ז). הדוח האחרון: [docs/DATA-AUDIT.md](docs/DATA-AUDIT.md).

```
docs/           היסטוריה, מחקר, specs ותוכניות

```

### ליבת הלוגיקה

- **תקנון** (תקנון הלימודים, עדכון 5.2.2026): אין חפיפה בין שיעורים (7.3), דרישת קדם חוסמת בשרשרת (7.4), קורס מקביל אפשר באותו סמסטר (6.2.3), קורס שנכשלת בו מוצע כחזרה (11.6.1), אזהרות על 3 כישלונות (11.4.1) ו-4 או 3 באותו קורס (11.5.1, 11.5.2), ומד התקדמות מול 70% (11.4.4).
- **ייצוג:** שבוע כמסכות של 32 ביט ליום, משבצת לחצי שעה בין 07:00 ל-23:00. בדיקת חפיפה היא AND.
- **ציון:** סכום משוקלל של חברים, התקדמות, ימים פנויים, חלונות, שעות מחוץ לטווח ופיזור בחינות. יש מגבלת זמן, ואם מגיעים אליה מוצגות תוצאות חלקיות עם סימון.
- **בחינות:** כשהלוח לא פורסם (`examsPublished: false`) הממשק מציג "טרם פורסם".

### אבטחה ופרטיות

- הכול נשמר ב-localStorage בדפדפן בלבד. אין שרת ואין חשבון.
- קישורי חבר וגיבוי הם קלט לא מהימן: אימות מבנה, מגבלות גודל (4KB, 64KB, ו-256KB אחרי פריסה), בנייה מחדש שדה אחרי שדה ו-`normalize()` לפני הכניסה למצב. כל טקסט מוצג דרך `esc()`.
- ספריות חיצוניות נטענות בעת הצורך בלבד, מ-CDN: panzoom (jsDelivr) בפתיחת מפת ההתקדמות, ו-pdf.js (cdnjs) או tesseract.js (jsDelivr, עם נתוני השפה עברית ואנגלית) בבחירת קובץ בעורך החבר. קובץ שנבחר נקרא בדפדפן ולא נשלח.
- הפונט מתארח מקומית ואין בקשות ל-Google Fonts.
