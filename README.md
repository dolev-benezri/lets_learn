## מה זה עושה

### מערכות מוכנות, בלי לשבץ ביד

ארבעה שלבים בסרגל בראש הדף: המצב שלי, קורסים, מה חשוב לי, מערכות. אתם קובעים מה חשוב לכם (ימים פנויים, בלי חלונות, שעות נוחות, להיות עם חברים) ומקבלים עד 10 מערכות מדורגות, מהטובה לפחות טובה. אפשר לבחור לפי מה לסדר אותן: הכי הרבה נ״ז, הכי הרבה עם חברים או הכי הרבה קורסי המשך. אפשר לתכנן שנה שלמה (עם קיץ, למי שמסמן שהוא מתכנן קיץ) או סמסטר אחד, ולנעוץ קבוצה שאתם רוצים בכל מקרה. בטלפון רואים יום אחד בכל פעם, ובמצב כהה או בהיר.

## התחלה מהירה

נכנסים [לאתר](https://dolev-benezri.github.io/lets_learn/). מאשרים את תנאי השימוש, עונים על שתי שאלות קצרות, ואחריהן ארבעה שלבים בסרגל בראש הדף. אפשר לקפוץ ביניהם בכל רגע. בכניסה הראשונה סיור קצר מראה את השלבים, ואפשר לראות אותו שוב מהכפתור "סיור באתר" בסרגל.

### 4. מה חשוב לי

מסמנים העדפות (ימים פנויים, בלי חלונות, שעות) ומוסיפים חברים (ראו [עם חברים](#עם-חברים)).

### 5. מערכות

המערכות נבנות מיד. מדפדפים בין החלופות עם החצים בראש הלוח, ולחיצה על שיעור פותחת פרטים ונעיצה. הכפתור "מפה" פותח את מפת ההתקדמות. בסוף פותחים את "רשימה להרשמה" ומעתיקים אותה לאפקה-נט, מדפיסים "סיכום ליועץ" לפגישה עם היועץ, או לוחצים "שתף" כדי לשלוח קישור לחבר. הכלי עוזר לתכנן, וההחלטה וההרשמה נשארות אצלכם ואצל ההכוון האקדמי.

**הצג לפי** נותן ארבע אפשרויות: מאוזן (לפי ההעדפות שלכם), הכי הרבה נ״ז, הכי הרבה עם חברים, ופותחת הכי הרבה קורסי המשך. הבחירה מסדרת את המערכות, אבל בתכנון שנה מלאה (שני סמסטרים) מערכת עם פחות קורסי חובה חסרים תמיד באה קודם. "הכי הרבה עם חברים" עובד רק כשיש חבר אחד לפחות שמוצג במערכת, ואחרת הסדר הוא "מאוזן".

## עוד יכולות

<details>
<summary>כל היכולות</summary>

- **מה חשוב לכם:** חברים, התקדמות בתואר, ימים פנויים, בלי חלונות, שעות נוחות ופיזור בחינות, כל אחד בארבע דרגות.
- **מה חייב להיות:** יום חופש, טווח שעות, מספר מרבי של ימים בקמפוס, או מרצה מסוים (או בלעדיו).
- **השוואה:** מחלופה 2 והלאה מופיעה שורה "לעומת חלופה 1" עם ההבדלים.
- **שנה מלאה:** זוג מערכות לסמסטר א׳ וב׳, כשקורס מא׳ פותח את ההמשך שלו בב׳. מי שמסמן "אני מתכנן/ת סמסטר קיץ" מקבל לשונית שלישית, קיץ, ליד א׳ וב׳. הקיץ מתוכנן מעל מערכת השנה ונספר בהתקדמות.
- **אזהרות לפי התקנון:** כשהממוצע או מספר הכישלונות מסכנים אתכם (לימודים על תנאי, הרחקה).
- **גיליון ציונים:** קובץ ה-PDF מהפורטל נקרא רק בדפדפן שלכם ולא נשמר. הציונים, הכישלונות והפטורים (פטור פנימי) מסומנים לבד, וקורס עם פטור מסומן "פטור" ברשימה.
- **אנגלית:** אם ציון האמירנט שלכם מספיק, קורסי האנגלית מסומנים כפטור.
- **התמחויות:** בחירת התמחות בשנה ג׳ לפי הכלל של המחלקה.
- **רשימת תיוג לסיום התואר:** ב"המצב שלי", כמה נ״ז נשארו בכל דרישה.
- **מפת ההתקדמות:** נפתחת מ"מפה" בשלב 4, עם זום וגרירה, מעבר בין חלופות בלי לאבד את הזום, וראשי תיבות לכל קורס.
- **ייצוא ליומן:** קובץ `.ics` בלי שיעורים בחגים, מתוך "רשימה להרשמה".
- **קישור גיבוי:** מעבירים את הנתונים לטלפון או למחשב אחר בלי להירשם.
- **נגישות:** מותאם לטלפון עד רוחב 320, ניווט מלא במקלדת, ובלי אנימציה למי שביקש להפחית תנועה. כל מסך נבדק אוטומטית מול WCAG 2.1 ברמה AA בדפדפן של Safari, בטלפון ובמחשב, בבהיר ובכהה. [מה נבדק ומה עוד פתוח](docs/ACCESSIBILITY-WCAG21.md) · [הצהרת נגישות (טיוטה, לפני בדיקה של מורשה נגישות)](https://dolev-benezri.github.io/lets_learn/legal.html#accessibility)

</details>

## פרטיות ונתונים

- **בלי הרשמה, ובלי שליחת הנתונים לשום מקום:** מה שסימנתם נשמר רק בדפדפן שלכם.
- **קישור גיבוי או קישור לחבר כולל את הנתונים שלכם בכתובת עצמה.** שולחים אותו רק למי שאתם רוצים.
- **הנתונים מתעדכנים כל לילה** מהידיעון הציבורי. בראש האתר כתוב מתי נבדקו לאחרונה, ובכל קבוצה כתוב "נכון ל-" עם השעה שבה נבדקו המקומות הפנויים.
- **כשמקורות רשמיים סותרים זה את זה** (תוכנית הלימודים מול הידיעון), האתר כותב זאת ב"המצב שלי" וממליץ לבדוק מול המחלקה. תוכנית שהמחלקה אישרה את הכללים שלה מסומנת "אושר על ידי המחלקה".
- **מצאתם שיעור שגוי או שעה לא נכונה, או שאתם רוצים שנסיר מידע?** [פותחים פנייה](https://github.com/dolev-benezri/lets_learn/issues/new/choose) (צריך חשבון GitHub).

## למפתחים

JavaScript נקי בלי build, אתר סטטי ב-GitHub Pages, וסריקה לילית של הידיעון ב-GitLab CI.

```mermaid
flowchart RL
  Y["ידיעון ציבורי"] --> S["scripts/scrape.mjs<br>כל לילה"] --> D["web/data/afeka/"] --> P["GitHub Pages"]
```

```bash
npm ci
npm test                      # בדיקות יחידה
npx playwright install webkit
npm run test:browser          # דפדפן אמיתי: נגישות (axe), זרימות מלאות והסיור
npm run report:rules          # דף כללים לכל תוכנית ומחזור, לאישור המחלקה (out/rules/)
npm run report:conflicts      # דף סתירות לכל מחלקה (docs/conflicts/)
npx http-server web -p 8080 -c-1
```
